LISEUSE CATALOGUE 2027 — MONDO PROD

Contenu :
- index.html
- catalogues/catalogue-fr.pdf
- catalogues/catalogue-en.pdf
- catalogues/catalogue-it.pdf
- catalogues/catalogue-es.pdf

Installation :
1. Envoyer le dossier "catalogue_reader_2027" sur votre hébergement web.
2. Garder la structure des dossiers exactement identique.
3. Le code charge les PDF avec des chemins relatifs :
   ./catalogues/catalogue-fr.pdf
   ./catalogues/catalogue-en.pdf
   ./catalogues/catalogue-it.pdf
   ./catalogues/catalogue-es.pdf
4. Dans votre page, vous pouvez intégrer index.html via une iframe de votre propre domaine,
   ou copier son contenu dans un bloc HTML personnalisé.
5. Pour que la langue soit automatique, la page doit idéalement avoir :
   <html lang="fr"> / <html lang="en"> / <html lang="it"> / <html lang="es">

Aucune connexion à Calaméo n'est utilisée dans cette liseuse.
